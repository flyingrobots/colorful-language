# Contributor workflows

Contributor workflows describe repository operations rather than Colorful's
product behavior. They are current operational contracts for maintainers and
agents.

Use this area for procedures such as release preparation, publishing,
repository maintenance, and other recurring work that changes how the project is
operated.

Product and user-facing concepts still belong in [`../topics/`](../topics/).

## Workflows

- [Release process](release-process/README.md) — release preparation, tag
  publication, verification, and retrospective discipline.
- [PR size reporting](pr-size-reporting/README.md) — informational line-count diff
  advisory signal and exclusions in CI.
- [Rust source policy](rust-source-policy/README.md) — first-party unsafe-code
  declarations, Cargo-target inventory, and reviewed exceptions.
