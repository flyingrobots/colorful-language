# ADR-0004: Generate portable IR structural admission

- Status: Accepted
- Date: 2026-07-28

## Context

`colorful.syntax/v1` crosses a process and language boundary. The Rust receiver,
the Graft reference consumer, and the independent Node consumer must reject
malformed artifacts before interpreting them. Rust uses generated DTOs plus
`validate_document`, but both JavaScript consumers currently repeat object
field sets, primitive checks, list checks, enum sets, and signed GraphQL `Int`
checks by hand.

The compatibility policy records three distinct identity generations that all
declare `colorful.syntax/v1`. A generator therefore cannot infer wire shape from
a release name or validate only the current workspace schema. Structural
generation also cannot replace invariants that GraphQL SDL cannot express:
source identity, UTF-8 boundaries, ordered non-overlapping ranges, token-axis
relationships, graph ownership and containment, and derivation identity.

## Decision

Treat each GraphQL SDL referenced by
`contracts/colorful/syntax-compatibility.v1.json` as the structural authority for
that generation. Generate one dependency-free JavaScript admission module that:

1. carries every registered generation by manifest id;
2. rejects missing or unknown object fields deterministically;
3. validates scalar, list, nullability, enum, and signed GraphQL `Int` shape;
4. visits fields in SDL order and list elements in wire order; and
5. reports structural failure through an adapter-supplied rejection callback.

Commit byte-identical generated copies for the Graft reference consumer and the
clean-room independent package. Both copies come from one generator and one
compatibility/SDL authority; regeneration drift is a blocking existing CI and
release gate.

The generated module owns structural admission only. Each consumer retains
named semantic stages for the invariants the SDL cannot encode. Graft maps a
generated rejection to `E_ARTIFACT_SHAPE`; the independent consumer maps it to
`E_SHAPE`. Existing semantic error categories and the cheap-to-expensive
validation order remain stable.

The burden ledger reports authored consumer lines and generated validator lines
separately. A reduction in handwritten adapter lines is not presented as a
total maintenance reduction merely because equivalent code moved into a
generator.

## Consequences

- A field or enum edit is authored in the generation SDL and changes both
  JavaScript consumers through deterministic regeneration.
- Released `v0.2.1` and `v0.3.0` artifacts remain selected by their complete
  compatibility identity; the workspace generation uses the same mechanism.
- The independent consumer remains a zero-dependency package and carries its
  generated runtime copy inside the clean-room boundary.
- Semantic admission remains reviewable by invariant name instead of being
  hidden in a generic schema interpreter.
- Generated bytes grow, but duplicated handwritten structural tables and
  checks stop being independent authorities.
